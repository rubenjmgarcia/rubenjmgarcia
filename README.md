## 🚀 Featured Project
 
### 🐠 Dive Logbook
 
My **CS50x Final Project**: a web app for logging scuba dives, built from 10 years of real diving experience.
 
With it, users can:
 
* Log and edit dives, and manage dive sites
* Track depth, duration and environmental conditions
* Record cylinder pressures and calculate SAC (surface air consumption) rate
* View dive statistics
* Store and query everything in a relational SQLite database
**Built with:** Python • Flask • SQLite • SQL • HTML • CSS • Jinja
 
➡️ **[View the Dive Logbook repository](https://github.com/rubenjmgarcia/dive-logbook)**
